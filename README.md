# Giraffe or Duck?

**Giraffe or Duck?** is a fun, challenging game where you guess if an image shows a giraffe or a duck. Keep track of your score, build streaks, and challenge yourself daily!

## Features
- **Simple Gameplay**: Just guess, score, and repeat!
- **Personal Profiles**: Track your progress and streaks.
- **Cross-Device Play**: Log in securely and play anywhere.

Jump in and see how many you can get right! 🦒🦆
